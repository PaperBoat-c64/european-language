# Translation Principles

How to translate authentic text for a learner, in priority order. These apply to the whole-text translation and every aligned sentence.

## Order of priorities

Translate to preserve, in this order:

1. **Propositional meaning** — what is claimed about the world. Nothing may be dropped or added.
2. **Illocutionary force** — is it a statement, question, request, warning, hedge? Preserve the act.
3. **Register and stance** — formal/casual, ironic, sarcastic, earnest. Preserve the distance.
4. **Imagery** — preserve the image only when it carries meaning; otherwise render the sense and note the image.

Never sacrifice a higher priority for a lower one. Word order is always the lowest priority.

## What "natural" means

The translation must read as if written in the explanation language by a native speaker of that language. Tests:

- A native speaker would not pause to wonder "what language was this translated from?"
- Idiomatic choices are used where they exist (English: "once upon a time", not "one time").
- No calques ("*está lloviendo gatos y perros*" must not become "it's raining cats and dogs" in a Spanish→English translation; use "it's raining heavily").

But "natural" never licenses changing meaning, register, or the speaker's stance to something more idiomatic.

## Idioms and culture

- Do **not** translate idioms word-for-word. Translate their *function*, then put the literal image in a note where it matters for the learner.
- Do **not** replace a source-culture reference with an explanation-language equivalent (a French *bac* is not "A-levels"). Keep the name and gloss it.
- Names, titles, dates, numbers, and quotations are left as they are.

## Preservation list

Preserve these exactly, inside any quoted text:

- every accent and diacritic (`é`, `ç`, `ñ`, `ü`, `ß`);
- the special letters `æ ø å` (Norwegian/Danish), `å ä ö` (Swedish);
- inverted punctuation `¿` `¡`;
- the source's apostrophes and quotation marks (`’` vs `'`, `« »`, `„ "`);
- hyphenation and capitalization.

Do not normalize to the explanation language's typography.

## Ambiguity and error handling

- **Ambiguity**: if a sentence genuinely has two readings, choose the one the context supports, translate that, and flag the alternative in the note. Do not silently pick.
- **Error in source**: translate what the source *says*, and flag the error in a note. Do not silently correct it.
- **Register loss**: if the explanation language cannot carry a register distinction (e.g. a T/V distinction with no equivalent), say so plainly in the "Losses" section.

## Output shape

The aligned translation has one entry per sentence: `Original` (verbatim), `Translation` (natural), `Literal` (only where useful), `Note` (only where useful). Notes are sparse — a note on every sentence is a sign of over-explaining.
